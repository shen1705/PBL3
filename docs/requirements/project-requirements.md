# PBL — Yêu cầu dự án

## 1. Sản phẩm và yêu cầu học phần

- Sản phẩm: phần mềm hoàn chỉnh kèm tài liệu đặc tả và thiết kế.
- Ngôn ngữ: được lựa chọn hoặc kết hợp nhiều ngôn ngữ; các hướng được gợi ý gồm .NET, Java và Python.
- Chức năng bắt buộc: đăng nhập, phân quyền và kết nối cơ sở dữ liệu MySQL.
- Kiến trúc: mô hình ba tầng kết hợp MVP/MVC; dự án lựa chọn ASP.NET Core MVC.
- Thư viện: được lựa chọn theo nhu cầu triển khai.
## 2. Yêu cầu về tiến độ

Theo hướng dẫn của giảng viên, giai đoạn từ đầu kỳ đến giữa kỳ tập trung vào lập kế hoạch, phân tích yêu cầu và thiết kế biểu đồ. Lập trình nghiệp vụ được thực hiện sau khi hoàn tất phân tích.

## 3. Kiến thức nền tảng

### C# và .NET

- Basic C#, OOP.
- LINQ cơ bản và các truy vấn phục vụ báo cáo, thống kê doanh thu.
- Entity Framework Core và truy cập cơ sở dữ liệu.
- ASP.NET Core MVC, ASP.NET Core Identity và API.

### Giao diện web

- HTML, CSS và JavaScript.

### Kiến trúc phần mềm

- Mô hình ba tầng, Repository Pattern và ViewModel Pattern.
- Thiết lập hệ thống và tương tác giữa các tầng.

### Quản lý mã nguồn

- Các thao tác Git: clone, branch và commit.

### Kiểm thử

- Phương pháp và quy trình kiểm thử.
- Thiết kế tình huống kiểm thử phục vụ lập trình và kiểm thử chất lượng.

### Tài liệu kỹ thuật

- UML: mục đích, cách sử dụng và cách đọc các loại biểu đồ.
- Đặc tả yêu cầu và chức năng.
